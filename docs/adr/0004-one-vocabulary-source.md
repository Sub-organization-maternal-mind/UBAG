# One vocabulary source: contract schemas generate status, event, and error-category sets

The job status, job event type, and error category vocabularies are declared once in `packages/shared-schemas` and `packages/openapi`; the SDK manifest generator (`tools/make-sdks/generate-manifest.mjs`) emits them to the TypeScript and Go SDKs and the dashboard, and the gateway derives its constants from the same set. Decided 2026-09-05 after the architecture survey found the 13-status vocabulary hand-copied in 10+ places with five invented failure sets, causing six of the eleven filed drift bugs (#49, #50, #51, #52, #54, #56 share the failure mode). Trade-off: hand-written unions are locally editable but demonstrably drift; generated sets turn drift into a `check:sdk-freshness` CI failure instead of a runtime bug. Rejected: unifying on the gateway's Go constants — contracts-first (ADR-0001) puts the source outside the contract layer.
