# P4.3 - Queue lease TTL, renewal, expiry reclaim and attempt-aware reaper

Status: merged (see PR). Flag-gated, inert by default (`UBAG_EXECUTOR_LEASE_TTL_MS` unset/0 = legacy behaviour).

## What landed
- `filespool.go`: `SetLeaseTTL`/`LeaseTTL`, `RenewLease` (touches the lease file; `ErrLeaseLost` if the file is gone), `ReclaimExpiredLeases` (leased/ files lapsed past the TTL go back to pending; duplicate of an existing pending envelope is parked in cancelled/, as in startup recovery), `RunLeaseReclaimer` (sweep every TTL/4). `RecoverOrphanLeases` is now the same routine with no expiry predicate (behaviour unchanged). Liveness of a lease = later of the lease time encoded in `<job>.<leaseNanos>.json` and the file mtime, because rename keeps the pending file's old mtime and a just-claimed lease of an old envelope must not look expired. Clock is the dispatcher's injectable `now`.
- `workerconsumer.go`: `ErrLeaseLost`; the existing 10 s heartbeat loop now cancels the local run when a renewal returns it (same treatment as a lost Exec Lease). The file-spool lease implements `LeaseHeartbeater` (no-op without a TTL). The cancel-watch now stops the run on ANY terminal job state (was: canceled only), so a job timed out by the stale-job reaper stops its running worker; the post-run path closes the lease (`finishTerminalLeasedJob`) instead of re-queuing a finished job.
- `reaper.go`: optional `Attempts jobs.AttemptStore`; when set, each sweep first calls `ExpireAttempts` so lapsed attempt leases are fenced before job fates are decided. Wired in `serve.go` only when `UBAG_EXECUTOR_ATTEMPTS` is on.
- `serve.go`: `UBAG_EXECUTOR_LEASE_TTL_MS` (0 or 30000..900000 ms, else startup error). File mode sets the spool TTL and starts the reclaimer; NATS mode uses the TTL as ack wait (the heartbeat's InProgress renews it, so the "ack wait must exceed max runtime" invariant is skipped only when the TTL is set).
- ADR-0007 addendum + ALLOCATION.md flag line: the queue lease is the carrier lease, not a third lease concept; Exec Lease (90/10) and Attempt Lease (120/20) are unchanged. No separate 120/20 for queues.

## Flags
| Flag | Default | Effect |
|---|---|---|
| `UBAG_EXECUTOR_LEASE_TTL_MS` | 0 (off) | Queue lease TTL; file-spool expiry reclaim + NATS ack wait. Off = legacy: leases never expire, startup recovery only. |

## Migrations
None.

## Checks run
- `gofmt -l`, `go vet ./internal/executor ./internal/serve`: clean.
- `go test ./internal/executor ./internal/serve -count=1`: pass. `go test -race ./internal/executor -run 'FileSpool|Reaper|LeaseLost|Heartbeat'`: pass.
- New (`lease_ttl_test.go`, `executor_lease_ttl_env_test.go`): reclaim before/after TTL with an injected clock, renewal keeps a lease alive and reports loss, TTL 0 is a no-op (startup recovery unchanged), old-envelope fresh lease not expired, reclaimer loop, NATS heartbeat -> `fakeNATSMsg.InProgress` (counter added), consumer cancels on `ErrLeaseLost` and does not complete/fail the lease, reaper timeout stops the running worker and completes (not retries) the lease, reaper expires lapsed attempts, env parsing/bounds and dispatcher wiring.

## Checks not run
- Real JetStream redelivery after the shortened ack wait (needs a NATS server); only the heartbeat call and config plumbing are covered.
- Postgres-backed `ExpireAttempts` from the reaper (P4.2's env-gated suite still pending). Full suites / docker per the targeted-only rule.

## Deviations
- The spec's new `LeaseRenewer` interface was not added: `LeaseHeartbeater` (workerconsumer.go) already is the optional renewal capability, and the NATS lease already calls `InProgress` through it (the spec's "never called today" is stale). I documented it as the renewal seam and added `ErrLeaseLost` instead of duplicating the interface.
- NATS expiry needs no new code beyond ack wait = TTL; JetStream owns redelivery.

## Follow-ups
- A reaper timeout still ends the job `timed_out`; the D4 `failed` + `reconcile_required` outcome for a submitted attempt belongs to P4.18.
- Production enablement: pick a TTL >= 30 s (suggest 120 s) and enable only after observing heartbeat stability on the loaded host (load ~10); a stalled gateway longer than the TTL gets its job re-run (guarded by the Exec Lease where shared admission is on).
