# P0.7 - Opt-in loopback pprof and Go runtime/process metrics

Status: merged-ready (see PR). Work items: baseline-09 = bench-07.

## Files
- `apps/gateway/internal/serve/pprof.go` (+ `pprof_test.go`): `startPprof`, wired in `serve.go` before the HTTP listener starts.
- `apps/gateway/internal/httpapi/runtime_metrics.go` (+ test): `writeRuntimeMetrics`, called at the end of `writeMetricsBody`.
- `tools/check-alert-metrics.mjs`: scan also collects `go_*`/`process_*` emitted names; `process_*` removed from the external allow-list.
- `tools/check-metrics-cardinality.mjs`: name rule now permits `go_`/`process_` prefixes.
- `apps/docs/.../operations/observability.md`, `deploy/vps/env.example`: documentation of the flag and series.

## Flag
`UBAG_PPROF_ADDR` - unset (default) = no listener. Host must be `127.0.0.1`, `::1` or `localhost`; `:port`, `0.0.0.0`, `[::]`, any other host or a malformed value is refused (warning logged, gateway continues without pprof). No auth surface added; own mux, not DefaultServeMux.

## Metrics added (always on, no flag; part of the existing 5 s cached render)
`go_goroutines`, `go_threads`, `go_memstats_heap_alloc_bytes`, `go_memstats_heap_inuse_bytes`, `go_memstats_sys_bytes`, `go_memstats_alloc_bytes_total`, `go_gc_cycles_total`, `go_gc_pause_seconds_total`, `go_gc_last_pause_seconds`, `process_start_time_seconds`; Linux-only via /proc: `process_cpu_seconds_total`, `process_resident_memory_bytes`, `process_open_fds` (omitted elsewhere). Cardinality: no labels.

## Migrations
None.

- `go test ./internal/serve -run Pprof`
- `go test ./internal/httpapi -run "RuntimeMetrics|ParseProcStat|Metrics"`

- `node tools/check-metrics-cardinality.mjs` fed a partial sample: no name-prefix violation for go_/process_ (only the expected "contract metric missing" lines because the sample was partial). Not run against a live `/v1/metrics` snapshot.

## Not run
Full gateway suites, live `curl` against a running gateway, /proc-backed series on Linux (the dev box is Windows; only the `/proc/self/stat` parser is unit tested).

## Deviations / notes
- A refused/malformed `UBAG_PPROF_ADDR` logs and continues rather than aborting startup (profiling is optional).
- `go_gc_duration_seconds` summary quantiles not emitted; `go_gc_pause_seconds_total` + `go_gc_last_pause_seconds` instead (dependency-light, no client_golang).
- `procClockTicks` fixed at 100 (USER_HZ).
