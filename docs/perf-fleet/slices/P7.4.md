# P7.4 Relay measurement hooks, real-libopus goldens and black-box seams

Status: partial. Hooks, seams, real-libopus tests and docs are merged and tested with FakeLib; the golden packet file is NOT yet recorded (no libopus on the dev box, no Docker allowed), so the byte-exact golden check skips until someone records it in the Debian image.

Files:
- deploy/vps/browser/audio-relay.py (RelayStats + seams)
- deploy/vps/browser/opus_bridge.py (`opus_version()`)
- deploy/vps/browser/tests/test_relay_stats.py (stats + seam tests, FakeLib)
- deploy/vps/browser/tests/test_opus_real.py (real libopus; module-level skip without libopus)
- deploy/vps/browser/tests/golden/opus_real_golden.json (placeholder: `libopus_version: null`)
- docker-compose.vps.yml, docker-compose.small.yml (pass `UBAG_VOICE_RELAY_STATS`, default 0)
- docs/load-testing.md ("Relay-side stats")

Flags (default): `UBAG_VOICE_RELAY_STATS` (off; `1/true/yes/on` enable). Seams, all defaulting to today's values and inert unless set: `UBAG_VOICE_MIC_PIPE` (/tmp/ubag-voice-mic.pcm), `UBAG_VOICE_PAREC` (parec), `UBAG_VOICE_PACTL` (pactl). Empty string counts as unset. Migrations: none.

Stats behaviour: one `audio-relay: stats {json}` line on stderr (-> /run/ubag/audio-relay.log through the existing entrypoint redirect) every 10 s while a session runs, plus a final line at session close. 1-in-10 frames timed, 512 samples max per window. Counters: mic_frames, mic_decode_errors, mic_fifo_dropped, mic_muted_discarded, speaker_frames, speaker_encode_errors; mic_fifo_bytes via FIONREAD (null off Linux). No protocol change; the relay 'stats' control op stays deferred.

Recording the golden (human step, Debian image or any host with libopus0):
`docker run --rm -v "$PWD":/w -w /w/deploy/vps/browser debian:bookworm-slim sh -c "apt-get update -qq && apt-get install -y -qq python3-pytest libopus0 && UBAG_OPUS_GOLDEN_UPDATE=1 python3 -m pytest tests/test_opus_real.py -q"`, then commit the updated golden JSON (it records the libopus version; the byte check only runs on that exact version, other versions skip with a message).

Checks run: `python -m pytest deploy/vps/browser/tests` (98 passed, 1 skipped = test_opus_real.py, no libopus on this Windows box; includes test_relay_vectors.py = P2.8 vectors green); `node tools/check-small-deployment.mjs`; `node tools/check-enterprise-deploy.mjs`.
Checks not run: test_opus_real.py against a real libopus (unavailable here; assertions are written but unexecuted, so their numeric bounds, e.g. RMS ratio 0.3-2.0 and silence-smaller-than-tone, are unverified); Docker image build; any live relay.

Deviations / notes:
- Gateway half of rust-03 (frame-age histogram, speaker WriteSample drop counter) was already delivered by P5.1; nothing added in apps/gateway.
- "Queue depth": the Python relay has no in-process queue, so depth is the mic FIFO fill (Linux only). The speaker side has no observable depth (parec pipe is buffered inside Popen).
- Timings exclude time waiting for the next frame by design.
- Adding an env passthrough to the two compose files recreates the browser container on the next deploy (it would anyway, the image changes).

Follow-ups: record the golden in the Debian image; consider extending the Go bench/acceptance harness to ingest the relay stats lines.
