# P5.3 Age-bounded mic and speaker queues

Status: merged (gateway code + tests + docs). The relay-side (Python) half was deliberately not changed, see deviations.

## Files

- `apps/gateway/internal/voice/media.go`: `MediaHub.QueueMaxAge`; mic pump drops a dequeued frame older than the bound (`mic_age`) before `relay.Send`; with the bound on, the speaker pump queues frames (64, drop-oldest, `speaker`) and a separate writer drops frames older than the bound (`speaker_age`). Shared `pushDropOldest` helper now also backs the mic enqueue (same behaviour). Speaker write/close handling factored into `writeSpeaker` (identical semantics, incl. `track_write_failed` + `speaker` drop count).
- `apps/gateway/internal/serve/serve.go`: `voiceQueueMaxAge` parses `UBAG_VOICE_QUEUE_MAX_AGE_MS` (non-positive/invalid = 0).
- `apps/gateway/internal/voice/media_age_test.go`: stalled-relay mic test, flag-0 preserves behaviour, 120 ms-packet count bound (mic and speaker), stalled speaker writer drops stale frames, speaker inline path with the flag off.
- `apps/gateway/internal/voice/media_bench_test.go`: bench honours `UBAG_VOICE_QUEUE_MAX_AGE_MS` for on/off comparison.
- `docker-compose.small.yml`, `deploy/small/env.example`, `docs/load-testing.md`: env pass-through (empty = off) and docs.

## Flags / env / migrations

- `UBAG_VOICE_QUEUE_MAX_AGE_MS`: default unset/0 = exactly the previous count-only behaviour. No migrations. No wire or contract change (drop `direction` label is free-form; two new values `mic_age`, `speaker_age`).

## Checks run

- `go vet ./internal/voice ./internal/serve`; `gofmt -l` clean
- `go test ./internal/voice -run 'Age|Stalled|CountBound|Inline' -count=3 -race`; `go test ./internal/voice -count=1` (whole package)
- P5.1 bench smoke (2 s windows, loopback, NON-AUTHORITATIVE), flag 0 vs 100 ms: p95 <= 0.54 ms (mic and speaker, 1/5/10/20 sessions) in both runs; sub-ms values are quantised by the Windows clock, so the bound adds no measurable latency on a healthy relay.

## Checks not run

- Full gateway suite, `pnpm check`, Postgres tests, real-relay/Docker voice run.

## Deviations

- Drop label for the speaker age drop is `speaker_age` (not plain `speaker`) so it does not collide with the existing `speaker` series (count-bound / write-failure drops).
- `deploy/vps/browser/audio-relay.py` and its test are unchanged: the relay's pumps are synchronous with no queue of their own, and the remaining buffers (kernel FIFO, pipe, TCP) belong to P7.6; a relay-side age bound would need a relay wire stamp, which the slice forbids.
- P2.8 was listed as a dependency but is not described as merged; nothing here depends on it.
