# P2.8 Relay protocol v2 shared vectors

Status: merged (contract + tests; one small gateway reader behaviour decision).

Files:
- packages/conformance/fixtures/voice-relay/v2.json (framing cases 0/1/65536/65537/huge/unknown types, token vectors incl. relay-test-secret/s1/1700000000, relay hello validation cases, reply reason enum, timing constants, control-frame cases)
- packages/shared-schemas/schemas/voice-relay-control.schema.json (hello/ready/error/mute; key order is not significant)
- packages/conformance/scripts/validate-fixtures.mjs (shape checks, HMAC recompute, control frames vs schema via a small built-in validator; no ajv dependency)
- deploy/vps/browser/tests/test_relay_vectors.py (Python relay consumer)
- apps/gateway/internal/voice/relay_vectors_test.go (Go consumer; replaces the Go-only token test in media_relay_test.go)
- apps/gateway/internal/voice/media.go (reader behaviour decision below)

Behaviour decision (the Go/Python asymmetry): the documented v2 wire says `1 <= length <= 65536`. Python already accepted length 1 (empty payload); Go rejected `< 2`. Go now accepts length 1 (matching the documented spec and Python) and drops empty audio packets in `Recv` (as Python does). Go's `readFrame` now also rejects unknown frame types at read time (previously `Dial` silently skipped them while `Recv` errored); Python already did. Go still never SENDS empty frames. Impact on live traffic: none expected (the relay never emits empty frames); only a malformed peer behaves differently.

Flags: none. Migrations: none.

Checks run: `node packages/conformance/scripts/validate-fixtures.mjs`; `go vet ./internal/voice`; `go test ./internal/voice -count=1` (all pass, 30 vector subtests); `gofmt -l internal/voice` (clean); `python -m pytest deploy/vps/browser/tests/test_relay_vectors.py` (38 pass) and `test_audio_relay.py` (37 pass).
Not run: full `pnpm test:conformance` / `pnpm check` (CLAUDE.md: targeted checks only); `pnpm lint:schemas` (needs ajv-cli via dlx; the new schema is plain draft-2020-12 and parses as JSON).

Deviations: the fixture adds `framing_note`/`hello_note` explaining case fields; oversize cases carry only the length/type (no body) so readers must refuse before reading it. The Python test lives under `deploy/vps/browser/tests` as specified and reuses the existing `rig` fixture.

Follow-ups: the Rust relay (P7.8) should consume the same fixture; the Go dialer has no hello validator, so hello validation vectors are asserted on the Python side and on Go's emitted hello shape only.
