## Flags (defaults)

- `UBAG_REDACT_REMOTE_ENDPOINT` - default off (legacy response shape preserved).
- `UBAG_PROFILE_OPTIONS_POLICY` - default `legacy` (inert); any value other than `namespaced` is legacy.

## Migrations

None. Schema impact check: `gateway_browser_instances.instance_id`, `gateway_provider_contexts.context_id`
and `gateway_browser_tabs.tab_id` are global primary keys in postgres/sqlite (migrations 0004/0008). Nothing in the gateway
writes those tables (only `MemoryStore` is a `TopologyIngestor`; SQL stores are read-only). If a SQL topology writer
is added (helper plane), it needs composite `(tenant_id, id)` keys first - that migration must be allocated then.

## Dashboard/mobile/SDK consumer check

`apps/dashboard/src/lib/api/types.ts` declares `remote_endpoint?` optional and nothing under `apps/dashboard/src` or
`apps/mobile` reads it. TS SDK type is optional. Go SDK and shared-schemas have no such field. Redaction is therefore safe to enable.

## Deviations

- `AddTab` signature unchanged; the tenant travels on a new non-serialised `BrowserTab.TenantID` to avoid changing the
  `TopologyIngestor` interface. An empty `TenantID` (legacy/test callers) falls back to resolving the first context with that id.
  Tabs for unknown contexts are now dropped rather than stored under an empty tenant (never visible before either).
- The spec's "tab context_id from trusted job record": the job record carries no context id, so the trust anchor is
  the job's tenant against that tenant's own contexts.
- Policy enforced worker-side only (the worker is the authoritative containment point; gateway only validates structure).

## Follow-ups

- Enabling `namespaced` relocates profiles (legacy default is `<root>/<target>/default`); plan a profile move or re-login
  window per tenant before flipping it in production. Consider a gateway-side check that rejects the three option keys under the same flag.
- Decide when to flip `UBAG_REDACT_REMOTE_ENDPOINT` on in production (no known consumer needs it). Voice control reads the store directly, not the HTTP response.
- Composite PK migration when a SQL topology writer lands.
