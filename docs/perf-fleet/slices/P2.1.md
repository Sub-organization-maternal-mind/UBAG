# P2.1 - Close dashboard, contract and fixture drift

Status: see PR (merged into `feat/perf-fleet` when the PR is merged). Size M. No dependencies. Contract-first: this lands before any new contract field.

## What changed

- `packages/conformance/fixtures/v0/scenarios.json`: browser summary/instances/contexts/tabs, `concurrency.list.ok` and `jobs.cancel.accepted` response bodies corrected to the OpenAPI field names (`browser_topology_summary`, `provider_contexts`, `concurrency_ceilings`; `target`/`identity_ref`/`min`/`max`/`in_flight`/`last_change_at`; tab `current_job_id`/`jobs_completed`; required `tenant_id`/`worker_id`/`created_at`; cancel response `metadata` + `events_url`).
- `packages/conformance/scripts/validate-fixtures.mjs`: Ajv (2020-12 + formats) validation of request and response bodies for every `browser`, `concurrency` and `jobs` scenario against `packages/openapi/openapi.yaml` (external shared-schema refs registered by `$id`). Previously structure-only. The old rule "browser tab rows must carry `has_storage_state`" was dropped for tabs (OpenAPI `BrowserTab` has no such field and is `additionalProperties: false`); the global `storage_state_uri` ban and the contexts `has_storage_state` rule stay.
- `packages/conformance/package.json` + `pnpm-lock.yaml`: dev dependencies `ajv`, `ajv-formats`, `yaml` (already in the lockfile graph; Ajv is the pre-agreed tool for this slice).
- `apps/dashboard/src/lib/api/types.ts`: `BrowserInstance/Context/Tab/Summary` mirror OpenAPI (legacy `id`/`status`/`url`/`title` aliases removed); new `ConcurrencyView` (`target`, `identity_ref`, `current_cap`, `min`, `max`, `in_flight`).
- `apps/dashboard/src/routes/browser/+page.svelte`: concurrency table reads `target/identity_ref/current_cap/max/in_flight` (was invented `provider_id/lane/maximum`); contexts table shows target + identity; tabs table shows conversation + current job instead of non-contract url/title.
- `apps/dashboard/src/routes/users/+page.svelte`: calls `/v1/scim/v2/Users` and `/v1/scim/v2/Groups` (the contract and gateway routes) instead of invented `/v1/scim/users|groups`.
- `apps/dashboard/src/lib/api/groupb-routes.test.ts`: asserts the SCIM paths and that every literal `/v1/...` path in any dashboard `+page.svelte` matches an `UBAG_ENDPOINTS` entry (template segments match any single segment).

## Flags / migrations

None. No runtime behaviour change; dashboard/test/fixture only.

## Deviations

- `novnc_url` is NOT in the OpenAPI `BrowserInstance` (and the gateway never emits it). It is kept as an explicitly commented, optional, non-contract field in `types.ts` because the page only embeds it when loopback-scoped; removing the viewer was out of scope. Follow-up: decide whether to add an operator-viewer contract or delete the iframe.
- Groups route was fixed along with users (same invented-path drift, same page).
- Fixture drift fixed beyond the three named scenario families only where Ajv flagged it (`jobs.cancel.accepted`).
