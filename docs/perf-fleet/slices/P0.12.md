## Behaviour added

- `events-latency`: N jobs, each with an SSE subscriber from creation to the terminal event. Latency = receive time minus `created_at`, both on the server clock; the offset comes from intersecting `Date`-header intervals (1 s resolution) and is reported with its uncertainty. Replayed backlog events are ignored; zero live samples is a FAIL.
- Optional idle phase (`--events-idle-seconds`): N subscribers hold finished jobs open; `/v1/metrics` deltas (request counters by route, DB pool, SSE connections) are taken over that window only.
- Optional `pg_stat_statements` delta via `--pg-stat-container` (read-only `docker exec psql`, never resets stats; skipped with a note when unavailable).
- `metricsDelta`: `requests_by_route` (`ubag_gateway_http_requests_total` folded per route with status_class split); `TRACKED` now covers the request counter, `ubag_sse_connections_current`, `ubag_worker_*`; the histogram handling is a `HISTOGRAMS` set (7 names incl. `ubag_job_stage_duration_seconds`) instead of two hard-coded names. The report prints the route table.
- Bug fixed on the way: `parseProm` dropped every series whose quoted label value contains `}` (the real gateway emits `route="/v1/jobs/{job_id}"`), so those series were silently missing from every metrics delta.

## Deviations / assumptions

- The spec says "/v1/events or per job". In this gateway `GET /v1/events` is a paged JSON list (handleEvents), not SSE, so only the per-job stream `/v1/sse/jobs/{id}` is probed.
- No latency threshold was invented: `event_latency_p95_ms` is reported only (D5: no lab host yet). The new gates are integrity gates.
- The k6 "SSE TTFB" probe was already removed by P0.5/D10; nothing to delete here.
- Live/backlog classification uses the calibrated offset, so with a loose calibration (`--events-calibrate-ms 0`) events created within the uncertainty of the subscribe instant may land on either side; use the default calibration for real runs.
- Adding the scenario to `--scenario all` means `all` runs now also open SSE streams (20 by default).
