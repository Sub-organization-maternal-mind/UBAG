Files:

Flags / env / migrations: none at runtime. The relay is unchanged; the bench uses the P7.4 seams (`UBAG_VOICE_MIC_PIPE`, `UBAG_VOICE_RELAY_STATS`, `UBAG_VOICE_PACTL` for `--pulse-check`).

What it measures (per relay process, N = 1/5/10 by default): CPU per call-minute, peak RSS, thread count, wake lag of a 10 ms sleeper thread inside the relay process, mic FIFO-full drops (from the relay's own stats line), p50/p95/max frame turnaround (mic: client send to FIFO read; speaker: fake-parec schedule to client receive, an upper bound that includes fake-parec scheduling lag), and CPU split into libopus / syscalls / other. The split is thread CPU time around the native libopus calls and the socket, FIFO and pipe calls (no ptrace needed). `--pyspy` adds `py-spy --native` and `--native --gil` on the first relay of each run; ctypes releases the GIL in libopus, so `--gil` shows GIL holders, not codec time. `--pulse-check` runs `pactl list short sinks|sources` and flags a sink/monitor whose spec is not 48 kHz mono s16le (hidden PulseAudio resampling).

Stop rule (evaluated first, in `evaluate_stop_rule`): STOP if libopus+syscalls >= 70% of relay CPU (rule A) or the relay < 5% of container CPU (rule B). Rule B needs `--container-cpu-pct`, the whole real container's CPU per live call, which only a real call can give; without it the verdict is `inconclusive` unless A already fires. The plan gate (>= 20% UBAG-controlled overhead, or >= 25% CPU/mem, material in the mixed workload; BINDING section 4) is reported next to it: overhead = relay CPU outside libopus+syscalls, memory saving is marked unevaluated (needs a Rust prototype's RSS), materiality needs the container figure. Verdicts: stop / continue / inconclusive / invalid (fake codec or no real FIFO).

How to record the verdict (human step, Debian-based browser image on an isolated container, never the shared VPS):
`docker run --rm --cap-add SYS_PTRACE -v "$PWD":/w -w /w/deploy/vps/browser <browser image or debian:bookworm-slim + python3 libopus0 pulseaudio-utils> python3 tests/bench_relay.py --sessions 1,5,10 --duration 30 --pulse-check --pyspy --host-class "<host>" --container-cpu-pct <X> --out relay-baseline.json`
(py-spy needs `pip install py-spy`; add `--lab-host` only on an isolated lab host, otherwise the report is labelled NON-AUTHORITATIVE). Record libopus version, host class and verdict in the ledger. On `stop`, close P7.6-P7.8 and keep P7.9.
