# P4.7 HelperAttemptSpec projection and helper env allowlist

Status: merged into `feat/perf-fleet`. Size M. Depends on P2.3, P3.5 (merged). Inert: nothing sends the spec or spawns a helper worker yet.

## Files

- `apps/gateway/internal/executor/helperspec.go` (new): `HelperAttemptSpec` is a separate type (not `DispatchEnvelope`) built by `NewHelperAttemptSpec(env, attemptID, profileRef)`. It carries ids, target, command type, conversation block, input and options, plus an opaque `profile_ref`. It drops `callbacks`, `client`, `context`, `idempotency_key`, `retry_of`, `not_before`, input `attachment_local_paths` / `audio_local_path`, and options `user_data_dir` / `profile_dir` / `profile_path`. `antigravity_*` targets return `ErrHelperTargetRefused`. `profile_ref` must match `^[A-Za-z0-9][A-Za-z0-9._:-]{0,127}$` (no paths). The projected spec is re-run through `payloadpolicy.Validate` and fails closed (`ErrHelperSpecInvalid`). `helperWorkerEnv()` = shared allowlist minus `UBAG_REMOTE_BROWSER_ENDPOINT` and `UBAG_NOVNC_BASE_URL`.
- `apps/gateway/internal/executor/workerconsumer.go`: the allowlist map is now package-level `workerEnvAllowed`; `minimalWorkerEnv()` = `filteredWorkerEnv(nil)`, behaviour unchanged (existing env tests pass).
- `apps/gateway/internal/executor/helperspec_test.go` (new): golden JSON test, struct-tag/key property test against the payloadpolicy denylist, refusal tests, helper-env equals local-minus-two test (also asserts local env still carries both).
