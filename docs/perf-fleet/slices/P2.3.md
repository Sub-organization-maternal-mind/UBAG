## Deviations / notes
- Work items disagreed on path (`ubag/v1/helper.proto` vs `ubag/helper/v1`); used the ALLOCATION.md path `ubag/helper/v1`. ADR 0006 already exists with another subject; no new ADR (ADR-0007 covers the lease contract).
- buf STANDARD lint forces `<Rpc>Response` names, so the stream element is `RunAttemptResponse{AttemptEvent event}`.
- Fence is not on Drain (node-scoped) or InspectAttempt (read-only; keyed by job_id+attempt_id). StageManifest is fenced because it stages for an attempt.
- RegisterNode is not a helper RPC: node registration is manager-grant driven (ADR-0006); Handshake covers version negotiation. ReportCapacity is named per the slice though the primary calls it (poll).
- Toolchain: plugins were installed via `go install` into a scratch dir (not committed). `buf.gen.yaml` has `clean: true`, which deletes gen/go/go.mod; regenerate with `buf generate --clean=false` (or restore go.mod/go.sum).
