## Decision D2 (admission rollout posture)

Shared admission and exec leases are accepted as live. They had no switch, so one was added:

- `UBAG_ADMISSION_SHARED` (default **true** = identical to today's live behaviour). `false`/`0`/`no`/`off` falls back to
  process-local admission counters and disables per-job execution leases (they share the SQL token backend, so the memory
  queue lease is the only duplicate guard). Only meaningful with sqlite/postgres stores; memory store is unaffected.
- Rollback caveat: tokens already held in SQL by in-flight jobs are not released by the local counters; they expire/sweep
  only while a shared backend runs, so flip the switch with the queue drained.
