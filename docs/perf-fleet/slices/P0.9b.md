# P0.9b - Stage timings: Python worker marks + mock adapter

Status: merged (Python worker only; Go emitters are P0.9c).

## What landed
- `apps/worker/ubag_worker/live/events.py`: `STAGE_KEYS` (closed set, mirrors job-event.schema.json `data.timings_ms` and observability `JOB_STAGES`), `StageTimer` (perf_counter, accumulating spans; unknown stage raises), `stage_timings_enabled()`.
- `apps/worker/ubag_worker/live/engine.py`: spans around real work. `worker_start` = payload normalize + driver creation; `browser_prep` = `driver.open`, `resume_thread`, `start_new_chat`, `ensure_provider_config`; `auth_check` = read-only login detection/polling (human manual-login wait excluded); `attachment_materialize` = `attach_files`; `provider_submit` = `submit_prompt`; `first_token` = submit-end to first delta; `provider_stream` = first delta to stream end (no-delta streams book the wait here); `extraction` = `read_final_response` + `dom_signature`. Retried interactions sum. Marks are monotonic, not event `created_at` (the engine buffers and replays events after the run).
- `adapters/mock/ubag_mock_adapter/adapter.py`: standalone marks (`worker_start`, `first_token`, `provider_stream`, `extraction`); the mock has no browser, so the other stages are absent (every key is optional).
- Timings ride only on the terminal `completed` event as `data.timings_ms`.
- `apps/worker/tests/test_stage_timings.py`: schema/key parity, accumulation, off-by-default (mock stays deterministic), closed-key non-negative output with real sleeps, mock opt-in.

## Flags
- `UBAG_WORKER_STAGE_TIMINGS` (default OFF; `1/true/yes/on` enables) for both the live engine and the mock adapter. Off keeps every event stream byte-identical, which the deterministic mock tests and conformance fixtures rely on. P0.9c / benchmark runs must set it on the worker to get stage attribution.
